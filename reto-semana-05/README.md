# Perfilador de Datasets
Herramienta que analiza archivos CSV y genera reportes de calidad de datos.

## Requisitos
- Python 3.8 o superior

## Instalación
1. Clonar el repositorio
2. Crear ambiente virtual: `python3 -m venv .venv`
3. Activar ambiente: `source .venv/bin/activate`
4. Instalar dependencias: `pip install -r requirements.txt`

## Uso
`python3 main.py --input data/ventas.csv --output outputs/perfil_ventas.csv`
